# AI-DESK とは

## ひとことで言うと

**AI-DESK は、手元の資料を AI に読ませて、まとめ・議事録・比較表などを作ってもらうための
作業場**です。いま開いているこのフォルダの全体を指します。

名前の由来は「机（デスク）」です。

> **資料は書庫から自由に持ってきて読めるが、書けるのは自分の机の上だけ。**

これが AI-DESK のいちばん大事な約束です。AI は許可された範囲の資料を自由に読めますが、
**書き込めるのは、あなたが出した依頼の `out` フォルダの中だけ**に制限してあります。
元の資料が、AI に勝手に書き換えられることはありません。

---

## 使い方（3ステップ）

### 1. この AI-DESK の中に、依頼の名前でフォルダを作る

```
AI-DESK\
    202610_見積比較\     ← これを新しく作る
```

### 2. その中に `task.md` を置いて、頼みたいことを書く

ひな形が `task_template\` にあります。**普通の日本語の文章で構いません。**
記号や書式は不要です。空欄があっても、そのまま始められます。

（以前配っていた `task.txt` で書かれた依頼も、そのまま使えます）

### 3. この AI-DESK のフォルダで AI を起動して、フォルダ名を伝える

```
202610_見積比較 をやって
```

結果は `202610_見積比較\out\` に出てきます。

**続きを頼むときは**「**〜の続き**」「**〜の1番で**」と言ってください。
前回の経緯は `out\00_作業記録.md` に残っているので、AI が途中から再開します。

## このフォルダに入っているもの

| 場所 | 役割 |
|---|---|
| `CLAUDE.md` | **AI-DESK の規則。** 全組織共通です。ここは直しません |
| `PROFILE.md` | **この組織の前提知識。** 業態・社内用語・資料の場所。自由に書き換えてください |
| `PROFILE.example.md` | `PROFILE.md` のひな形（記入例） |
| `GEMINI.md` | Antigravity 用の案内板（`CLAUDE.md` を読ませるためのファイル） |
| `.claude\skills\` | 定型業務の手順（`疎通確認`、`継続タスク`） |
| `.claude\settings.local.json` | **読んでよいフォルダの指定。** この PC・この組織の設定です |
| `task_template\` | 依頼の書き方とひな形 |
| `bin\` | Python の自動導入スクリプト |
| `.ai-desk\VERSION` | **この AI-DESK の版番号。このファイルがある場所が AI-DESK の入口です** |

## 読んでよいフォルダを決める（`.claude\settings.local.json`）

AI が読めるのは、**この AI-DESK の中と、ここに書いたフォルダだけ**です。
初回に一度だけ設定してください（以後は触りません）。

`.claude\settings.local.json.example` をコピーして `.claude\settings.local.json` という名前にし、
中の一覧をあなたの環境に書き換えます。

```json
{
  "permissions": {
    "additionalDirectories": [
      "Z:/20_営業",
      "Z:/40_会議"
    ]
  }
}
```

書き方の決まりは3つだけです。

1. **区切りは `/`（スラッシュ）で書く。** `\`（円記号）ではありません。ここだけの決まりです
2. フォルダはいくつでも並べられます。**行の末尾に `,`（カンマ）を付け、最後の行だけ付けません**
3. **範囲は狭いほど安全です。** `Z:/` 全体ではなく、必要なフォルダを挙げてください

書き換えたあとは、**AI をいったん終了して起動し直してください。**
うまく効いているかは `疎通確認` で確かめられます。

> このファイルは**この PC・この組織だけの設定**です。配布物には含まれません。
> どこに何があるかの説明は `PROFILE.md`、読んでよいかの許可はこのファイル、と役割が分かれています。

## AI-DESK は、いくつ置いてもかまいません

AI-DESK は**フォルダごとコピーして使えます。** 同じ PC にも、共有フォルダにも、
いくつでも置けます。**フォルダ名も自由です。**

```
Z:\個人\山田太郎\AI-DESK       ← 通常業務用
Z:\個人\山田太郎\AI-DESK2      ← 別案件用
C:\Users\yamada\AI-DESK        ← 手元の PC で作業するとき
Z:\共有\営業部\AI-DESK         ← 部署で共同作業するとき
```

AI がここを AI-DESK だと判断する目印は、**フォルダ名ではなく `.ai-desk\VERSION` の有無**です。
だから名前を変えても壊れません。

新しく作りたいときは、**管理者に頼んでください**（コピーの仕方が決まっています）。

## 覚えておいてほしいこと

- **AI が確認なしで書き込めるのは `<タスクフォルダ>\out\` の中だけ**です。
  それ以外の場所へ書こうとすると、**必ず画面に確認が出ます。**
  身に覚えのない書き込みの確認が出たときは、**承認せずに断ってください。**
- **初回の起動時だけ「このフォルダを信頼しますか」の確認が出ます。必ず承諾してください。**
  ここで断ると設定がすべて無視され、資料が読めません。
  「資料が読めない」というときは、まずここを疑ってください。
- **`CLAUDE.md` を、この場で直さないでください。** これは配布物のコピーで、
  AI-DESK の数だけ存在します。ここを直しても他には伝わらず、次の更新で消えます。
  直したいところがあれば、AI に改訂案を `out\` に出させて、管理者に渡してください。
- この組織の事情（用語・資料の場所など）は **`PROFILE.md`** に書きます。こちらは自由です。
- **スキルは、この AI-DESK の中で育てて構いません。** よく使う手順を
  「スキルにして」と頼めば、AI が `.claude\skills\` に作ります（そのとき確認が出ます）。
  ただし**最初から入っている `疎通確認` と `継続タスク` を直接書き換えると、
  次の更新で消えます。** 手を入れたいときは、別の名前でコピーを作ってください。

## よくある質問

**Q. AI-DESK は Claude Code のことですか**

いいえ。AI-DESK は**この作業場と規則の名前**です。
Claude Code でも Antigravity でも、ここで作業するときは AI-DESK の規則に従います。
将来使う道具が変わっても、名前は変わりません。

**Q. 以前の資料に、いまと違うフォルダの場所が書いてあります**

**書き換えないでください。** 当時の記録です。読むときに現在の場所へ読み替えます。
読み替えのルールは `PROFILE.md` に書いてあります。

**Q. 昨日まで読めた資料が、急に読めなくなりました**

まず「このフォルダを信頼しますか」に承諾しているかを確認してください。
AI-DESK のフォルダを移動したり名前を変えたりすると、この確認が再度出ます。
承諾していないと、資料が一切読めません。

**Q. うまく動いているか確かめたい**

AI に `疎通確認` と伝えてください。環境を一通り点検し、**この AI-DESK の版番号**も教えてくれます。

**Q. 自分の AI-DESK は最新ですか**

`疎通確認` で版番号が分かります。管理者が持っている配布元の版と見比べてください。
（配布元が設定されている場合は、`疎通確認` が自動で比べます）
