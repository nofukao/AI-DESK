# AI-DESK とは

> このファイルは、この AI-DESK を使う**人**に向けた案内です。
> **AI 向けの規則は `CLAUDE.md` にあります。** 食い違っていたら `CLAUDE.md` が正です。

## ひとことで言うと

**AI-DESK は、手元の資料を AI に読ませて、まとめ・議事録・比較表などを作ってもらうための
作業場**です。いま開いているこのフォルダの全体を指します。

名前の由来は「机（デスク）」です。

> **資料は書庫から自由に持ってきて読めるが、書けるのは自分の机の上だけ。**

これが AI-DESK のいちばん大事な約束です。AI は許可された範囲の資料を自由に読めますが、
**書き込めるのは、あなたが出した依頼の `out` フォルダの中だけ**に制限してあります。
元の資料が、AI に勝手に書き換えられることはありません。

---

## はじめて使うとき（最初に一度だけ）

### 1. AI-DESK のフォルダを用意する

管理者から受け取るか、配られた AI-DESK のフォルダを、使いたい場所へコピーします。
**フォルダ名は自由**です（`AI-DESK` のままでも、`AI-DESK2` でも構いません）。

> **いま使っている AI-DESK を、コピーして増やさないでください。**
> 依頼のフォルダ（中身は業務の資料や成果物）まで一緒にコピーされてしまいます。
> 新しく増やすときは、**配られたままの AI-DESK** から作ってください。

### 2. そのフォルダで AI（Claude Code）を起動する

**VS Code を使う場合**

1. VS Code で、**AI-DESK のフォルダを開く**（「ファイル」→「フォルダーを開く」）
2. 「**このフォルダの作成者を信頼しますか**」と聞かれたら、**信頼する**を選ぶ
3. Claude Code の画面を開く

**ターミナル（PowerShell）を使う場合**

```powershell
cd "<AI-DESK のフォルダ>"
claude
```

### 3. 【重要】「このフォルダを信頼しますか」に、必ず承諾する

初回だけ、Claude Code がこの確認を出します。**必ず承諾してください。**

**ここで断ると設定がすべて無視され、資料を読めず、書き込みの制限も効きません。**
「資料が読めない」というときは、まずここを疑ってください。

### 4. 「初期設定」と言う

作ったばかりの AI-DESK には、次の2つが**まだありません。**

| ファイル | 中身 | 無いとどうなるか |
|---|---|---|
| `PROFILE.md` | この組織の前提知識（業態・社内の言葉・資料の場所） | 依頼のたびに確認が増える |
| `.claude\settings.local.json` | 読んでよいフォルダ | **この AI-DESK の中しか読めない** |

**どちらも AI が対話で作ります。** こう言ってください。

```
初期設定
```

- **聞かれたことに答えるだけです。** ファイルを開いて書く必要はありません
- 質問は1つずつ出ます。**分からなければ「分からない」「飛ばして」で構いません**
- 読んでよいフォルダは、AI が**一覧を見せてくれるので、選ぶだけ**です
- 「**要らない**」と答えても構いません。前提知識が無くても、AI-DESK は動きます

### 5. AI を起動し直す

**設定は、AI を起動したときに読み込まれます。** 初期設定が終わったら、必ず起動し直してください。
**そのままでは、選んだフォルダはまだ読めません。**

- **VS Code の場合**: VS Code をいったん閉じて、もう一度 AI-DESK のフォルダを開く
- **ターミナルの場合**: `/exit` で終了して、もう一度 `claude`

### 6. 「疎通確認」と言う

```
疎通確認
```

AI が環境を一通り点検します。**この AI-DESK の場所と版番号**、読めるフォルダ、
書き込みの制限が効いているか、を報告します。**問題があれば、次に何をすればよいかも教えてくれます。**

これで準備は終わりです。

## 使い方（ふだん）

### 1. この AI-DESK の中に、依頼の名前でフォルダを作る

```
AI-DESK\
    202610_見積比較\     ← これを新しく作る
```

**フォルダ名がそのまま依頼の呼び名**になります。あとで見て中身がわかる名前にしてください。

### 2. その中に `task.md` を置いて、頼みたいことを書く

ひな形が `task_template\` にあります。**普通の日本語の文章で構いません。**
記号や書式は不要です。空欄があっても、そのまま始められます。

（以前配っていた `task.txt` で書かれた依頼も、そのまま使えます）

### 3. AI を起動して、フォルダ名を伝える

```
202610_見積比較 をやって
```

結果は `202610_見積比較\out\` に出てきます。

**続きを頼むときは**「**〜の続き**」「**〜の1番で**」と言ってください。
前回の経緯は `out\00_作業記録.md` に残っているので、AI が途中から再開します。

## このフォルダに入っているもの

**最初から入っているもの**

| 場所 | 役割 |
|---|---|
| `CLAUDE.md` | **AI-DESK の規則。** 全組織共通です。**ここは直しません** |
| `README.md` | このファイル（人向けの案内） |
| `GEMINI.md` | Antigravity 用の案内板（`CLAUDE.md` を読ませるためのファイル） |
| `PROFILE.example.md` | `PROFILE.md` の記入例（手で書きたい人向け） |
| `.claude\settings.json` | 書き込みの制限。**ここは直しません** |
| `.claude\settings.local.json.example` | `settings.local.json` の記入例（手で書きたい人向け） |
| `.claude\skills\` | 定型業務の手順（`初期設定`、`疎通確認`、`継続タスク`） |
| `task_template\` | 依頼の書き方とひな形 |
| `bin\` | Python の自動導入スクリプト |
| `.ai-desk\VERSION` | **この AI-DESK の版番号。このファイルがある場所が AI-DESK の入口です** |

**あとから作られるもの**

| 場所 | 役割 | いつ作られるか |
|---|---|---|
| `PROFILE.md` | **この組織の前提知識。** 自由に書き換えてください | 「初期設定」のとき |
| `.claude\settings.local.json` | **読んでよいフォルダの指定。** この PC・この組織の設定です | 「初期設定」のとき |
| `<依頼の名前>\` | あなたが作る依頼のフォルダ。成果物は中の `out\` に出ます | 依頼するとき |
| `00_疎通確認\` | 「疎通確認」の点検記録 | 「疎通確認」のとき |
| `.ai-desk\source.txt` | この AI-DESK がどこから配られたか（版の確認に使います） | 管理者が作ったとき |

`PROFILE.md` と `settings.local.json` は、**この PC・この組織だけのもの**です。配布物には含まれず、
AI-DESK を更新しても上書きされません。

## AI-DESK は、いくつ置いてもかまいません

AI-DESK は**フォルダごとコピーして使えます。** 同じ PC にも、共有フォルダにも、
いくつでも置けます。**フォルダ名も自由です。**

```
Z:\個人\山田太郎\AI-DESK       ← 通常業務用
Z:\個人\山田太郎\AI-DESK2      ← 別案件用
C:\Users\yamada\AI-DESK        ← 手元の PC で作業するとき
Z:\共有\営業部\AI-DESK         ← 部署で共同作業するとき
```

AI がここを AI-DESK だと判断する目印は、**フォルダ名ではなく `.ai-desk\VERSION` の有無**です。
だから名前を変えても壊れません。

**管理者のスクリプト（`new-instance.ps1`）で作ってもらうと、**
**「この AI-DESK は最新か」を `疎通確認` が自動で調べられるようになります。**
手でコピーした場合も使えますが、この確認だけは「確認できませんでした」になります。

## 覚えておいてほしいこと

- **AI は「自動」のモードで使う前提で作ってあります。** いちいち確認を出さずに作業を進めるためです。
  そのぶん、**資料フォルダ・規則・設定ファイルへの書き込みは、確認ではなく設定そのもので
  禁止**してあります。AI が「拒否されました」と言った場合は、規則から外れたことをしようとしています
- **ただし、禁止を設定しきれない場所もあります。** AI-DESK の外（デスクトップなど）への書き込みは、
  自動のモードでは確認なしで通ることがあります。**成果物の場所は、AI が毎回フルパスで報告します。**
  `out\` 以外の場所が書かれていたら、その場で AI に伝えてください
- **確認を出して、ひとつずつ承認しながら使うこともできます。** Claude Code の権限モードを
  切り替えてください。その場合、**身に覚えのない書き込みの確認が出たら、承認せずに断ってください**
- **`CLAUDE.md` を直さないでください。** これは配布物のコピーで、AI-DESK の数だけ存在します。
  ここを直しても他には伝わらず、次の更新で消えます（AI は、設定により書き換えられません）。
  直したいところがあれば、AI に改訂案を `out\` に出させて、管理者に渡してください
- この組織の事情（用語・資料の場所など）は **`PROFILE.md`** に書きます。こちらは自由です。
  「PROFILE に足して」と言えば、AI が書き足します
- **スキルは、この AI-DESK の中で育てて構いません。** よく使う手順を「スキルにして」と頼めば、
  AI が内容を説明し、あなたの同意を得てから `.claude\skills\` に作ります。
  ただし**最初から入っているスキル（`初期設定`・`疎通確認`・`継続タスク`）を直接書き換えると、
  次の更新で消えます。** 手を入れたいときは、別の名前でコピーを作ってください

## よくある質問

**Q. AI-DESK は Claude Code のことですか**

いいえ。AI-DESK は**この作業場と規則の名前**です。
Claude Code でも Antigravity でも、ここで作業するときは AI-DESK の規則に従います。
将来使う道具が変わっても、名前は変わりません。

**Q. 資料が読めません**

次の順に確かめてください。

1. **「このフォルダを信頼しますか」に承諾しましたか。** AI-DESK のフォルダを移動したり
   名前を変えたりすると、この確認が再度出ます
2. **読みたいフォルダを、読んでよい範囲に入れましたか。** 入っていなければ「**初期設定**」と言って、
   フォルダを足してください（「`○○` のフォルダも読めるようにして」でも伝わります）
3. **足したあと、AI を起動し直しましたか。** 起動し直すまで効きません

**Q. 読んでよいフォルダを増やしたい／減らしたい**

「**初期設定**」と言うか、「`○○` も読めるようにして」と伝えてください。
AI が `.claude\settings.local.json` を書き換えます。**そのあと AI を起動し直してください。**

範囲は**狭いほど安全**です。ドライブ全体を読める範囲にすると、検索が終わらなくなることもあります。

**Q. PROFILE.md や settings.local.json を、手で書きたい**

`PROFILE.example.md` と `.claude\settings.local.json.example` が記入例です。
コピーして、名前から `.example` を外し、中身を書き換えてください。

- `PROFILE.example.md` の**1行目**（`AI-DESK-PROFILE-EXAMPLE` と書いてある行）は、**必ず消してください。**
  残っていると、AI は「まだ記入例のまま」と判断して、中身を使いません
- `settings.local.json` では、フォルダの区切りを **`/`（スラッシュ）** で書きます。`\` ではありません。
  また、読める場所には、**必ず同じ場所の書き込み禁止（`deny`）も書いてください**（記入例のとおり）

**Q. 以前の資料に、いまと違うフォルダの場所が書いてあります**

**書き換えないでください。** 当時の記録です。読むときに現在の場所へ読み替えます。
読み替えのルールは `PROFILE.md` に書きます。

**Q. うまく動いているか確かめたい**

AI に `疎通確認` と伝えてください。環境を一通り点検し、**この AI-DESK の版番号**も教えてくれます。

**Q. 自分の AI-DESK は最新ですか**

`疎通確認` で版番号が分かります。管理者が持っている配布元の版と見比べてください。
（管理者のスクリプトで作った AI-DESK なら、`疎通確認` が自動で比べます）
