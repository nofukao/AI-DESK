# AI-DESK とは

> このファイルは、この AI-DESK を使う**人**に向けた案内です。
> **AI 向けの規則は `CLAUDE.md` にあります。** 食い違っていたら `CLAUDE.md` が正です。

## ひとことで言うと

**AI-DESK は、手元の資料を AI に読ませて、まとめ・議事録・比較表などを作ってもらうための
作業場**です。いま開いているこのフォルダの全体を指します。

名前の由来は「机（デスク）」です。

> **資料は書庫から自由に持ってきて読めるが、書けるのは自分の机の上だけ。**

これが AI-DESK のいちばん大事な約束です。AI は資料を読めますが、
**書き込めるのは、いま取り組んでいる依頼のフォルダの中だけ**に制限してあります。
元の資料が、AI に直接書き換えられることはありません。

---

## はじめて使うとき（最初に一度だけ）

### 1. AI-DESK のフォルダを用意する

管理者から受け取るか、配られた AI-DESK のフォルダを、使いたい場所へコピーします。
**フォルダ名は自由**です（`AI-DESK` のままでも、`AI-DESK2` でも構いません）。

> **いま使っている AI-DESK を、コピーして増やさないでください。**
> 依頼のフォルダ（中身は業務の資料や成果物）まで一緒にコピーされてしまいます。
> 新しく増やすときは、**配られたままの AI-DESK** から作ってください。

### 2. そのフォルダで AI（Claude Code）を起動する

**VS Code を使う場合**

1. VS Code で、**AI-DESK のフォルダを開く**（「ファイル」→「フォルダーを開く」）
2. 「**このフォルダの作成者を信頼しますか**」と聞かれたら、**信頼する**を選ぶ
3. Claude Code の画面を開く

**ターミナル（PowerShell）を使う場合**

```powershell
cd "<AI-DESK のフォルダ>"
claude
```

### 3. 【重要】「このフォルダを信頼しますか」に、必ず承諾する

初回だけ、Claude Code がこの確認を出します。**必ず承諾してください。**

**ここで断ると、書き込みの制限が効きません。** AI がタスクフォルダの外にも書けてしまいます。

### 4. 「初期設定」と言う

作ったばかりの AI-DESK には、**`PROFILE.md`（この組織の前提知識）がまだありません。**
業態・社内の言葉・資料の場所などを書いておくファイルで、無いと依頼のたびに確認が増えます。

**AI が対話で作ります。** こう言ってください。

```
初期設定
```

- **聞かれたことに答えるだけです。** ファイルを開いて書く必要はありません
- 質問は1つずつ出ます。**分からなければ「分からない」「飛ばして」で構いません**
- 資料のあるフォルダは、AI が**一覧を見せてくれるので、選ぶだけ**です
- **AI に読ませたくないフォルダ**（人事・給与など）があれば、ここで伝えられます。無ければ不要です
- 「**要らない**」と答えても構いません。前提知識が無くても、AI-DESK は動きます

**読んでよいフォルダを設定する必要はありません。** 資料は、依頼ごとに必要なところを読みます。

### 5. 「疎通確認」と言う

```
疎通確認
```

AI が環境を一通り点検します。**この AI-DESK の場所と版番号**、資料を読めるか、
**書き込みの制限が効いているか**、を報告します。**問題があれば、次に何をすればよいかも教えてくれます。**

途中で「わざと間違った場所へ書き込もうとします」と言われます。**止められるのが正しい動作です。**

これで準備は終わりです。

### 【覚えておいてください】初めて AI-DESK の外の資料を読むとき

AI が初めて AI-DESK の外（`Z:` など）の資料を読むとき、Claude Code が
「この先も読み続けてよいか」を英語で確認してくることがあります。

| 表示 | どうするか |
|---|---|
| **Keep allowing** | **これを選んでください** |
| Block from now on | **選ばないでください。** この PC のすべての作業で、AI-DESK の外を読めなくなります |
| Ask again next time | 今回は読まず、次にまた聞かれます |

## 使い方（ふだん）

**AI を起動して、そのまま話しかけてください。** フォルダも依頼書も、AI が用意します。

```
メールの差出人名簿を作ってほしいです。
Z:\30_総務\受信メール のメールから差出人の署名を抽出して、名簿にしてください。
形式は xlsx で。重複はまとめて、差出人ごとの件数も入れてください。
```

AI が `差出人名簿\` のようなフォルダを作り、**その中に**結果を出します。
このフォルダを **タスクフォルダ** と呼びます（依頼1件につき1つです）。
**始める前に「`出力先: …`」と示されます。** 名前が気に入らなければ、あとから変えて構いません。

```
AI-DESK\
    差出人名簿\
        00_作業記録.md                       ← これまでの経緯
        01A_依頼内容.md                      ← AI が「こう頼まれた」と理解した内容
        01B_差出人名簿_2026-09-16.xlsx        ← 成果物
        02A_依頼内容.md                      ← 2回目に頼んだこと
        02B_差出人名簿_2026-09-17.xlsx        ← 2回目の成果物
```

**名前の読み方は、これだけです。**

- 頭の **`01` `02`** は、**何回目の依頼か**
- **`A` があなたの依頼、`B` がその結果**

次回からは「**差出人名簿 の続き**」と言えば、そこから再開します。
**前の回の成果物は消えません。** 「短くして」と頼んだ回も、結果は `02B_…` という別のファイルになります。

**直すファイルや名前は、あなたが決めることもできます。**
「**今後は 02B を直して**」「**今後は 議事録.md を直していって**」と言えば、新しい番号のファイルを増やさず、
そのファイルを毎回直していきます。「**今回だけ 議事録.md という名前で出して**」のような頼み方もできます。
直す前の版は、AI が `材料\` の中に残します。元の出し方に戻すときは「**元に戻して**」と言ってください。

タスクフォルダが増えて見通しが悪くなったら、**古いものを `_保管庫\` に移してください**（移すのはあなたです）。
`_保管庫_仕事` `_保管庫_趣味` のように、**名前が `_保管` で始まるフォルダ**なら、いくつ作っても構いません。
保管したタスクも、「**見積比較 の続き**」と言えば、AI が保管庫の中から見つけて確かめたうえで、その場所のまま続けます。
「**_保管庫_仕事\見積比較 の続き**」のように場所まで言えば、確認なしで続けます。

- **資料の場所は、できるだけ伝えてください。** 書いていなければ AI が聞いてきます
- **AI は `00_TASK.md` を作りません。** `00_TASK.md` は、あなたが書く依頼の原本だからです。
  AI が言われたことを書き留めるのは `01A_依頼内容.md` の方です

**次の「使い方（込み入った依頼のとき）」は、同じ依頼を繰り返すときや、話し言葉で伝えきれないときの形です。**
書いておけば、毎回同じ品質になります。

## 使い方（込み入った依頼のとき）

### 1. この AI-DESK の中に、依頼の名前でフォルダを作る

```
AI-DESK\
    202610_見積比較\     ← これを新しく作る
```

**フォルダ名がそのまま依頼の呼び名**になります。あとで見て中身がわかる名前にしてください。

### 2. その中に `00_TASK.md` を置いて、頼みたいことを書く

ひな形が `00_タスクテンプレート\` にあります。**普通の日本語の文章で構いません。**
記号や書式は不要です。空欄があっても、そのまま始められます。

**AI は、`00_TASK.md` の「見る場所」に書いた場所の資料だけを読みます。**
書き方は `00_タスクテンプレート\README.md` にあります。

**名前は `00_TASK.md` です。** この名前以外は使えません。

### 3. AI を起動して、フォルダ名を伝える

```
202610_見積比較 をやって
```

結果は、**同じ `202610_見積比較\` の中**に出てきます。

**続きを頼むときは**「**〜の続き**」「**〜の1番で**」と言ってください。
前回の経緯は `00_作業記録.md` に残っているので、AI が途中から再開します。

## このフォルダに入っているもの

**最初から入っているもの**

| 場所 | 役割 |
|---|---|
| `CLAUDE.md` | **AI-DESK の規則。** 全組織共通です。**ここは直しません** |
| `README.md` | このファイル（人向けの案内） |
| `GEMINI.md` | Antigravity 用の案内板（`CLAUDE.md` を読ませるためのファイル） |
| `PROFILE.example.md` | `PROFILE.md` の記入例（手で書きたい人向け） |
| `.claude\settings.json` | 書き込みの制限の設定。**ここは直しません** |
| `.claude\hooks\` | 書き込み先を確かめる仕組み（AI が書く直前に働きます）。**ここは直しません** |
| `.claude\skills\` | 定型業務の手順（`初期設定`、`疎通確認`、`新規タスク`、`継続タスク`） |
| `00_タスクテンプレート\` | 依頼の書き方とひな形（`00_TASK.md`） |
| `bin\` | Python の自動導入と、履歴の一覧を直すスクリプト |
| `_保管庫\` | **古いタスクフォルダの置き場。** あなたが移します。`_保管` で始まる名前なら、改名しても、増やしても構いません |
| `.ai-desk\VERSION` | **この AI-DESK の版番号。このファイルがある場所が AI-DESK の入口です** |

**あとから作られるもの**

| 場所 | 役割 | いつ作られるか |
|---|---|---|
| `PROFILE.md` | **この組織の前提知識。** 自由に書き換えてください | 「初期設定」のとき |
| `<依頼の名前>\` | タスクフォルダ。**AI が作るか、あなたが作ります**（→「使い方（ふだん）」）。成果物は、このフォルダの中に直接出ます | 依頼するとき |
| `00_疎通確認\` | 「疎通確認」の点検記録 | 「疎通確認」のとき |
| `.ai-desk\source.txt` | この AI-DESK がどこから配られたか（版の確認に使います） | 管理者が作ったとき |

`PROFILE.md` は、**この組織だけのもの**です。配布物には含まれず、AI-DESK を更新しても上書きされません。

## AI-DESK は、いくつ置いてもかまいません

AI-DESK は**フォルダごとコピーして使えます。** 同じ PC にも、共有フォルダにも、
いくつでも置けます。**フォルダ名も自由です。**

```
Z:\個人\山田太郎\AI-DESK       ← 通常業務用
Z:\個人\山田太郎\AI-DESK2      ← 別案件用
C:\Users\yamada\AI-DESK        ← 手元の PC で作業するとき
Z:\共有\営業部\AI-DESK         ← 部署で共同作業するとき
```

AI がここを AI-DESK だと判断する目印は、**フォルダ名ではなく `.ai-desk\VERSION` の有無**です。
だから名前を変えても壊れません。

**管理者のスクリプト（`new-instance.ps1`）で作ってもらうと、**
**「この AI-DESK は最新か」を `疎通確認` が自動で調べられるようになります。**
手でコピーした場合も使えますが、この確認だけは「確認できませんでした」になります。

> **ネットワークドライブ（`Z:` など）に置く場合**、Claude Code の不具合で、履歴の一覧が出ないことがあります。
> AI-DESK は、これを自動で直します（→ よくある質問「過去の会話（履歴）が、一覧に出てきません」）。

## 覚えておいてほしいこと

- **AI は「Auto」モードで使う前提で作ってあります。** いちいち確認を出さずに作業を進めるためです。
  そのぶん、**AI が直接書き込める場所は、確認ではなく設定そのもので限って**あります。
  書けるのは **タスクフォルダの中・`PROFILE.md`・`.claude\skills\` の中だけ**で、
  資料フォルダも、デスクトップも、ほかの場所も止まります。
  **あなたが書いた `00_TASK.md` も、AI には書き換えられません。**
  タスクフォルダに資料を置いた場合、AI は頼まれない限り書き換えませんが、これは設定では止めていません（AI への約束です）
  AI が「書き込み制限で止められました」と言った場合は、規則から外れたことをしようとしています
- **ただし、止めきれないものが1つあります。AI が作ったプログラム（Python など）が書き出すファイル**です。
  設定の制限は、プログラムの中までは見張れません。AI には、書き出し先を実行前に必ず確かめる規則を課しています

  **成果物の場所は、AI が毎回フルパスで報告します。** タスクフォルダ以外の場所が書かれていたら、その場で AI に伝えてください
- **確認を出して、ひとつずつ承認しながら使うこともできます。** Claude Code の権限モードを
  切り替えてください。その場合、**身に覚えのない書き込みの確認が出たら、承認せずに断ってください**
- **`CLAUDE.md` を直さないでください。** これは配布物のコピーで、AI-DESK の数だけ存在します。
  ここを直しても他には伝わらず、次の更新で消えます（AI は、設定により書き換えられません）。
  直したいところがあれば、AI に改訂案をタスクフォルダへ出させて、管理者に渡してください
- この組織の事情（用語・資料の場所・**AI に読ませたくない場所**など）は **`PROFILE.md`** に書きます。こちらは自由です。
  「PROFILE に足して」と言えば、AI が書き足します
- **スキルは、この AI-DESK の中で育てて構いません。** よく使う手順を「スキルにして」と頼めば、
  AI が内容を説明し、あなたの同意を得てから `.claude\skills\` に作ります。
  ただし**最初から入っているスキル（`初期設定`・`疎通確認`・`新規タスク`・`継続タスク`）を直接書き換えると、
  次の更新で消えます。** 手を入れたいときは、別の名前でコピーを作ってください

## よくある質問

**Q. AI-DESK は Claude Code のことですか**

いいえ。AI-DESK は**この作業場と規則の名前**です。
Claude Code でも Antigravity でも、ここで作業するときは AI-DESK の規則に従います。
将来使う道具が変わっても、名前は変わりません。

**Q. 資料が読めません**

**読んでよいフォルダを設定する必要はありません。** 次の順に確かめてください。

1. **そのフォルダを、エクスプローラーで開けますか。** ネットワークドライブが繋がっていないことがあります
2. **「Block from now on」を選んだことはありませんか。** 初めて AI-DESK の外を読むときの確認でこれを選ぶと、
   外を読めなくなります。AI に `疎通確認` と伝えると、直し方を案内します
3. **依頼の「見る場所」に書いてありますか。`PROFILE.md` の「AI に読ませない場所」に入っていませんか。**
   「見る場所」に無い場所は、AI が開く前に確認します。「AI に読ませない場所」は開きません

**Q. AI に読ませたくないフォルダがあります**

その依頼だけのことなら、**依頼の「見る場所」に書かないでください。**
AI は「見る場所」に書いた場所だけを読み、ほかも見る必要が出たときは、開く前に聞いてきます。
いつも読ませたくない場所（人事・給与など）は、`PROFILE.md` の「**AI に読ませない場所**」に書きます。
「**初期設定**」と言うか、「`○○` は読ませないで、と PROFILE に足して」と伝えてください。

どちらも **AI への約束**で、機械的に読めなくする設定ではありません。

**Q. PROFILE.md を、手で書きたい**

`PROFILE.example.md` が記入例です。コピーして `PROFILE.md` という名前にし、中身を書き換えてください。

- **1行目**（`AI-DESK-PROFILE-EXAMPLE` と書いてある行）は、**必ず消してください。**
  残っていると、AI は「まだ記入例のまま」と判断して、中身を使いません

**Q. 以前の資料に、いまと違うフォルダの場所が書いてあります**

**書き換えないでください。** 当時の記録です。読むときに現在の場所へ読み替えます。
読み替えのルールは `PROFILE.md` に書きます。

**Q. うまく動いているか確かめたい**

AI に `疎通確認` と伝えてください。環境を一通り点検し、**この AI-DESK の版番号**も教えてくれます。

**Q. 自分の AI-DESK は最新ですか**

`疎通確認` で版番号が分かります。管理者が持っている配布元の版と見比べてください。
（管理者のスクリプトで作った AI-DESK なら、`疎通確認` が自動で比べます）

**Q. 過去の会話（履歴）が、一覧に出てきません**

AI-DESK を**ネットワークドライブ（`Z:` など）に置いている**と起きます。
Claude Code 側の不具合で、**履歴は消えていません。**

**AI-DESK は、セッションを始めるたびに、これを自動で直します**
（あなたのユーザーフォルダに、同じフォルダへの別の入口を1つ作るだけです）。
その PC で初めて使ったときに直るので、ふだんは気にしなくて構いません。

それでも出ないときは、AI に「**履歴が出ない**」と伝えてください。状態を調べ、直してよいか聞いてきます。
「このフォルダを信頼しますか」に承諾していないと、自動では直りません。

**AI-DESK 以外のフォルダ**で同じ症状が出たときは、AI-DESK の `bin\setup_history.ps1` を1つだけ、
そのフォルダの Claude Code に渡し（チャットに添付するか、そのフォルダに置く）、「**これを実行して**」と頼んでください。
