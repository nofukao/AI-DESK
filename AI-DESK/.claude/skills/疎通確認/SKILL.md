# 疎通確認 — 作業環境の点検

この AI-DESK のインスタンスが正しく動いているかを、上から順に確認して報告してください。
**業務データには一切書き込まないこと。** 確認はすべて読み取りのみで行います。

## 1. ここがインスタンスのルートか

カレントディレクトリに **`.ai-desk\VERSION`** があるか確認し、**版番号**を読む。

- **ある** → そのフルパスと版番号を報告する（例: 「`C:\Users\yamada\AI-DESK`、版 1.0.0」）
- **無い** → ここは AI-DESK のインスタンスではない。**その旨を伝えて点検を中止する。**
  AI-DESK のフォルダに移動して起動し直すよう案内する

## 2. 規則を読めているか

`CLAUDE.md` を読み、冒頭の「役割と目的」が取得できるか確認する。

## 3. この組織の前提知識があるか

`PROFILE.md` があるか確認する。

- **ある** → 正常
- **無い** → 「`PROFILE.example.md` をコピーして `PROFILE.md` を作ってください」と案内する。
  **不具合ではありません。** 無くても規則はすべて有効であることを添える

## 4. 共通スキルが読み込まれているか

このスキル（疎通確認）自体が呼び出せている時点で、`.claude\skills\` は有効です。
**「有効」と報告してください。**

## 5. 資料を読めるか（読み取り範囲と、信頼ダイアログの確認）

`.claude\settings.local.json` を読み、`permissions.additionalDirectories` の一覧を取り出す。

- **ファイルが無い** → 「読んでよいフォルダがまだ設定されていません。
  `.claude\settings.local.json.example` をコピーして作ってください」と案内する
- **ある** → **その一覧をユーザーに見せる。** さらに、そのうち1つに対して
  Glob などの内蔵検索をかけ、ファイルを列挙できるか確かめる
  - 列挙できた → 正常
  - 権限エラーになった → **信頼ダイアログが未承諾**の可能性が高い。次を案内すること。
    「Claude Code をこのフォルダで対話モードで一度起動し、
    『このフォルダを信頼しますか』の確認に承諾してください。
    承諾しないと settings.json の設定がすべて無視されます。」

## 6. Python が使えるか

**`python` ではなく `py` を使い、ライブラリまで確かめる。**

```powershell
py -c "import sys, openpyxl, pandas, docx, pptx, pdfplumber; print(sys.executable)"
```

- **実体のパスが返った → 正常**
- **エラー → 使えない。** 次のどれかを切り分ける。
  - `py` が無い、または Python 本体が無い → **導入の可否をユーザーに確認したうえで**
    `powershell -NoProfile -ExecutionPolicy Bypass -File "<インスタンスのルート>\bin\setup_python.ps1"`
    を実行し、**終了後に Claude Code の再起動を案内する。**
  - Python はあるがライブラリが足りない → **確認不要。** `py -m pip install` で入れる。

**「パスが返ったか」だけで判定しないこと。** 次の2つは実体のパスを返すが**使ってはいけない**。

- `WindowsApps` を含むもの → Microsoft Store の誘導用スタブ（偽物）
- **別アプリ同梱の Python**（例: `C:\Program Files\Inkscape\bin\python.exe`）
  → 抽出ライブラリが入っておらず、**そこへ `pip install` すると他アプリの環境を壊す**

参考として `python` が何を指しているかも見ておき、上のどちらかだった場合は
**「`python` は別物を指しているので、`py` を使ってください」とユーザーに伝える。**

## 7. インスタンスの構成

カレントディレクトリ直下に次があるか確認する。無いものは指摘する。

- `CLAUDE.md`
- `GEMINI.md`
- `.claude\settings.json`
- `task_template\`
- `bin\`

不足していれば、**配布物から作り直すか、管理者に更新を依頼するよう案内する**
（AI が勝手にコピーしない）。

あわせて、**インスタンスの中に `.git` が無いこと**を確認する。
**あった場合は異常**として報告すること。インスタンスは Git のクローンではありません
（→ `CLAUDE.md` 絶対遵守ルール2）。

## 8. 書き込み範囲の確認

`.claude\settings.json` を読み、`permissions.allow` に
`Write(*/out/**)` と `Edit(*/out/**)` が入っているか確認する。

## 報告のしかた

1〜8 を表にまとめ、**問題があった項目だけ**、次に何をすればよいかを添えて報告する。
**インスタンスのフルパスと版番号は、問題が無くても必ず示すこと**（1 の結果）。
それ以外がすべて正常なら「問題なし」と一行で締めてよい。
