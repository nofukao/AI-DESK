# _保管庫 — 古いタスクフォルダの置き場

> このファイルは、AI-DESK を使う**人**に向けた案内です。
> **AI 向けの規則は `CLAUDE.md` にあります。** 食い違っていたら `CLAUDE.md` が正です。

タスクフォルダが増えて見通しが悪くなったら、**もう使わない（しばらく使わない）タスクフォルダを、
このフォルダに移してください。** 移すのはあなたです。AI は移動しません。

```
<AI-DESK>\
    差出人名簿\               ← いま使っているタスクフォルダ
    _保管庫\
        202610_見積比較\       ← 移したタスクフォルダ
        議事録_9月\
```

## 決まりは、これだけです

- **名前が `_保管` で始まるフォルダが、保管庫です。**
  `_保管庫_仕事`、`_保管庫_趣味` のように改名しても、いくつ増やしても構いません
- 保管庫の中に置くのは、**タスクフォルダだけ**です。保管庫の中に、さらに保管庫は作れません（1段だけです）
- 保管庫の中のタスクフォルダに、AI は新しいタスクを作りません。新しいタスクは、いつも `<AI-DESK>\` の直下にできます

## 保管したタスクの続きをやりたいとき

**元の場所に戻さなくても、そのまま続けられます。**

| 頼み方 | AI がすること |
|---|---|
| 「**202610_見積比較 の続き**」 | 保管庫の中から見つけて、「`_保管庫\202610_見積比較` のことですか」と確かめてから続けます |
| 「**_保管庫\202610_見積比較 の続き**」 | 確認なしで、そこで続けます |

同じ名前のタスクフォルダが2か所以上にあるときは、AI がどれのことか聞きます。

## このフォルダが要らないとき

使わないなら、このフォルダは消して構いません。
ただし、AI-DESK を新しい版に更新すると、**この案内（`_保管庫\README.md`）がまた作られます。**
`_保管庫` を改名して使っている場合も、同じです。そのときは、また消してください。
