# 00_タスクテンプレート — AI への依頼テンプレート置き場

> このファイルは、AI-DESK を使う**人**に向けた案内です。
> **AI 向けの規則は `CLAUDE.md` にあります。** 食い違っていたら `CLAUDE.md` が正です。

このフォルダは**テンプレートの保管場所**です。ここで作業は行いません。
このテンプレートは、AI 作業環境 **AI-DESK** で使います。

以下の説明で `<AI-DESK>` と書いてある部分は、
この `00_タスクテンプレート\` フォルダが入っている**AI-DESK のフォルダ**に読み替えてください。

---

## その前に —— ふだんは、そのまま話しかけてください

**いつもの頼み方は、AI にそのまま話しかけることです。**
フォルダも依頼書も、AI が用意します（→ 下の「その場で頼む」）。

```
メールの差出人名簿を作ってほしいです。
Z:\30_総務\受信メール のメールから差出人の署名を抽出して、名簿にしてください。
形式は xlsx で。重複はまとめて、差出人ごとの件数も入れてください。
```

**このフォルダのテンプレートを使うのは、次のようなときだけです。**

- **同じ依頼を、何度も繰り返す**（毎月の集計など）。書いておけば、毎回同じ品質になります
- **依頼が込み入っている**。話し言葉で伝えきるより、書いた方が早くて確実です
- **頼む人と、作業を見る人が違う**。何を頼んだかが残ります

---

## 使い方（3ステップ）

### 1. 依頼内容を表す名前のフォルダを作る

`<AI-DESK>\` の直下に作ります。日本語の名前で構いません。

```
<AI-DESK>\
    202610_見積比較\     ← これを新しく作る
```

**フォルダ名がそのまま依頼の呼び名**になります。あとで見て中身がわかる名前にしてください。

### 2. このフォルダから `00_TASK.md` をコピーして、中身を埋める

コピーしたら、**ファイル名は `00_TASK.md` のままにしてください。**

`.md` という拡張子ですが、**中身は普通の日本語の文章で構いません。**
メモ帳でそのまま開いて書けます。見出しや記号の書き方を覚える必要はありません。

`<!--` と `-->` で囲まれた部分は説明と記入例です。消しても、残したままでも構いません。

項目は次の5つです。**空欄があっても構いません。**

| 項目 | 書くこと |
|---|---|
| 概要 | 何についての依頼か |
| 見る場所（場所と説明） | AI に読ませる資料の場所と、そこに何があるか。**ここに書いた場所以外は、AI は見ません** |
| 依頼事項、考慮事項 | AI にしてほしいこと。**欲しいものの形（md / xlsx / docx など）・分量・読み手も、ここに書きます** |
| 注意してほしいこと | 守ってほしい書き方や扱い |
| ここまで出来ていれば完成という条件 | できあがりの目安 |

### 3. AI に頼む

`<AI-DESK>` のフォルダをカレントディレクトリにして AI を起動し、こう伝えます。

```
202610_見積比較 をやって
```

結果は、**同じ `202610_見積比較\` の中**に出てきます。

```
<AI-DESK>\
    202610_見積比較\
        00_TASK.md                          ← あなたが書いた依頼
        00_作業記録.md                       ← これまでの経緯（AI が書く）
        01A_依頼内容.md                      ← AI が「こう頼まれた」と理解した内容
        01B_見積比較_3社版_2026-10-15.md      ← 成果物
        02A_依頼内容.md                      ← 2回目に頼んだこと
        02B_見積比較_4社版_2026-10-18.md      ← 2回目の成果物
        材料\                               ← AI が使った道具・途中のデータ
```

**名前の読み方は、これだけです。**

- 頭の **`01` `02`** は、**何回目の依頼か**
- **`A` があなたの依頼、`B` がその結果**

`A` と `B` が対になっているので、**どの依頼から何が出てきたか**が一目でわかります。
**前の回の成果物は残ります。** 「短くして」と頼んだ回でも、結果は `02B_…` という
**別のファイル**になり、元のものは消えません。見比べて、どちらを使うか決められます。

## よくある質問

### Q. その場で頼む —— 依頼書を書かずに頼めますか

**それがふだんの頼み方です。** AI に、そのまま話しかけてください。

```
メールの差出人名簿を作ってほしいです。
Z:\30_総務\受信メール のメールから差出人の署名を抽出して、名簿にしてください。
形式は xlsx で。重複はまとめて、差出人ごとの件数も入れてください。
```

AI が次をやります。

1. `差出人名簿` のような**フォルダを作る**（名前は AI が付けます）
2. `01A_依頼内容.md` に、**あなたが言ったことをそのまま書き留める**
3. 作業して、同じフォルダに `01B_…` という名前で成果物を出す

**フォルダ名は、作業を始める前に「出力先: …」という形で示されます。**
気に入らなければ、**あとからあなたがフォルダの名前を変えて構いません**（AI は変えません）。

次回からは「**差出人名簿 の続き**」と言えば、そこから再開します。

- **資料の場所は、できるだけ伝えてください。** 書いていなければ AI が聞いてきますが、
  一度で伝わった方が速く済みます
- **AI は `00_TASK.md` を作りません。** `00_TASK.md` は、あなたが書く依頼の原本だからです。
  AI が書き留めるのは `01A_依頼内容.md` の方です。
  こうしておくと、あとから**「この条件は自分が言ったのか、AI が補ったのか」が分かります**
- `01A_依頼内容.md` が気に入って、これを毎回使いたくなったら、**コピーして `00_TASK.md` という名前で
  置いてください。** 次からはテンプレート方式になります

### Q. Markdown の書き方がわかりません

**気にしなくて大丈夫です。** 普通の日本語の文章で書いてください。
`#` や `-` といった記号は無くても、まったく同じように伝わります。

極端な話、これだけでも機能します。

```
事務所の給湯器を交換したいです。
業者3社の見積を比較して意見をください。
資料は Z:\20_営業\設備\給湯器 にあります。
A4一枚くらいでお願いします。
```

### Q. 項目を全部埋められません

**空欄のままで大丈夫です。** 埋まっている情報だけで AI は作業を始めます。
どうしても必要な情報があれば、AI の方から聞いてきます。

### Q. どの項目が一番大事ですか

**「見る場所」**です。

共有フォルダには数千から数万のファイルが入っていることも珍しくなく、その多くは
今回の依頼と無関係です。場所の見当がついていると、作業時間と正確さが大きく変わります。

正確なパスがわからなくても、「営業部の設備関係の資料」程度の手がかりで十分役に立ちます。

### Q. 文字コードは何にすればいいですか

**気にしなくて大丈夫です。** メモ帳でそのまま保存すれば問題ありません。

### Q. ファイル名は必ず `00_TASK.md` ですか

はい。この名前だと AI が自動的に見つけます。
**この名前以外は使えません**（`TASK.md`・`task.md`・`task.txt` は、もう探しません）。

頭の `00_` は「このタスク全体のもの」という印です。
`01A_` `01B_`（その回のもの）より上に並びます。

### Q. 2回目以降の結果を、前回とは別のフォルダに出してほしい

**その必要はありません。** 回ごとに `02B_…` `03B_…` と**別のファイル**になるので、
前の回の成果物が消えることはありません。

`out2` に出す仕組みは、この版で廃止しました。1回で3つ以上のファイルが出るときだけ、
AI が `02B_タイトル_2026-10-18\` というフォルダにまとめます。

### Q. 1つのファイルを、何回も直しながら仕上げたい

「**1つのファイルで直していって**」と頼んでください。最初の回でも、途中の回からでも頼めます。

```
<AI-DESK>\
    議事録\
        00_作業記録.md
        00_議事録.md                 ← 毎回これを開けば最新
        01A_依頼内容.md
        02A_依頼内容.md
        材料\
            01B_議事録_2026-10-15.md  ← 1回目の版（控え）
            02B_議事録_2026-10-16.md  ← 2回目の版（控え）
```

- 成果物は `00_議事録.md` のような**1つのファイル**になり、AI が毎回それを直します
- **各回の版は消えません。** 回の終わりごとに、`材料\` の中へ控えが残ります
- 途中の回から頼んだときは、それまでの `01B_…` `02B_…` はそのまま残ります
- 同じものを何回か直していると、AI の方から「1つのファイルにしますか」と提案することがあります。
  **頼まない限り、AI が勝手に切り替えることはありません**

### Q. AI が勝手に資料を書き換えてしまうことはありませんか

**AI が直接書き込めるのは、依頼フォルダの中の、決まった名前のファイルだけです。**

- `00_作業記録.md` `00_議事録.md` / `01A_…` `01B_…` のように**番号で始まる名前** / `材料\` の中
- **`00_TASK.md`（あなたが書いた依頼）は、AI には書き換えられません**

資料のあるフォルダも、デスクトップも、ほかの場所も、**設定そのもので止めてあります**
（「このフォルダを信頼しますか」に承諾していれば）。
確認が出て、うっかり承認してしまう心配もありません。

`<AI-DESK>\` の直下に**新しい依頼フォルダを作ること**だけはできます（→「その場で頼む」）。

ただし、AI が作ったプログラム（Python など）が書き出すファイルは、この制限では止まりません。
そのため AI には、**書き出し先を実行前に必ず自分で確かめる**規則を課しています。

**出した場所は、AI が毎回フルパスで報告します。** 依頼フォルダ以外の場所が書かれていたら、
その場で AI に伝えてください。

### Q. AI に読ませたくない資料があります

その依頼だけのことなら、**`00_TASK.md` の「見る場所」に書かないでください。**
AI は「見る場所」に書いた場所だけを読みます。ほかの場所も見る必要が出たときは、開く前に聞いてきます。

いつも読ませたくない場所（人事・給与など）は、`PROFILE.md` の「**AI に読ませない場所**」に書きます
（「初期設定」と言えば、対話で書けます）。

どちらも **AI への約束**で、機械的に読めなくする設定ではありません。

## 書くときのコツ

- **目的を先に書く。** 「何のためにこれが欲しいのか」がわかると、AI の判断がぶれません
- **欲しい形を「依頼事項」に書く。** 「docx で A4一枚」「比較表」など。指定がないと分量がばらつきます
- **わからないことは「わからない」と書く。** 「どこにあるか不明」と書いてあれば、AI はまず探すところから始めます

## 注意

- このフォルダ（`00_タスクテンプレート`）自体は、実行対象のタスクではありません。
  「00_タスクテンプレート をやって」と頼まないでください。
- テンプレートを直接書き換えず、**必ずコピーしてから**使ってください。
- このフォルダは**配布物**です。AI-DESK の数だけ写しが存在します。
  ここを直しても他の AI-DESK には伝わらず、次の更新で消えます。
  内容を直したいときは、**管理者に依頼してください。**
