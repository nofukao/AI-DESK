# 最初に必ず実行すること

ここは AI 作業環境 **AI-DESK** のインスタンスです。

作業を始める前に、必ずターミナルで次の2つを実行し、
出力された内容を読み込んで、以降それに従ってください。

    type CLAUDE.md
    type PROFILE.md

- `CLAUDE.md` — **AI-DESK の規則**です。他のどのルールより優先されます。
- `PROFILE.md` — **この組織の前提知識**です（業態・社内用語・資料の置き場所など）。

`PROFILE.md` が見つからない場合は、まだ作られていません。
**無いまま作業を進めてかまいません**（規則はすべて有効です）。
ユーザーには「Claude Code で『**初期設定**』と言えば、対話で作れます」と案内してください。

`PROFILE.md` の中に **`AI-DESK-PROFILE-EXAMPLE`** という行がある場合は、
**記入例のままです。中身は架空の会社の情報なので、事実として扱わないでください。**

---

## 【重要】あなたには機械的な歯止めがありません

`.claude\settings.json` による書き込みブロックは **Claude Code だけの機能**です。
**あなたが間違った場所に書けば、確認プロンプトは出ず、そのまま書き込まれます。**

したがって、**書き込みの直前に必ず自分でパスを読み上げて確認**してください。

    出力先: <インスタンスのルート>\<タスク名>\out\

**そのパスにタスクフォルダ名が入っているか** ——
これだけ見れば、ほとんどの事故は防げます。
カレントディレクトリ直下の `out` は、いかなる場合も使いません。

---

## このファイルについて

AI-DESK の規則の実体は **`CLAUDE.md`** です。
このファイルは、そこへの**案内板にすぎません。**

**ここにルールを書き足さないでください。** 二重管理になり、必ず食い違います。

`CLAUDE.md` の中では、エージェント固有の項目に
**【Claude Code のみ】** / **【Antigravity のみ】** の印がついています。
自分に該当しない項目は読み飛ばしてください。

なお `CLAUDE.md` は**配布物のコピー**です。**この場で直接編集しないでください。**
規則を直したいときは、改訂案を `<タスクフォルダ>\out\` に出力し、管理者に渡してください。
