# 最初に必ず実行すること

ここは AI 作業環境 **AI-DESK** のインスタンスです。

作業を始める前に、必ずターミナルで次の2つを実行し、
出力された内容を読み込んで、以降それに従ってください。

    type AGENTS.md
    type PROFILE.md

- `AGENTS.md` — **AI-DESK の規則**です。他のどのルールより優先されます。
- `PROFILE.md` — **この組織の前提知識**です（業態・社内用語・資料の置き場所など）。

`PROFILE.md` が見つからない場合は、まだ作られていません。
**無いまま作業を進めてかまいません**（規則はすべて有効です）。
ユーザーには「Claude Code で『**初期設定**』と言えば、対話で作れます」と案内してください。

`PROFILE.md` の中に **`AI-DESK-PROFILE-EXAMPLE`** という行がある場合は、
**記入例のままです。中身は架空の会社の情報なので、事実として扱わないでください。**

---

## 【重要】あなたには、タスクフォルダ単位の機械的な歯止めがありません

AI-DESK が用意した書き込みの制限（`.claude\settings.json` と `.claude\hooks\`）は、**Claude Code だけの機能**です。
あなたの道具に別の制限があっても、**タスクフォルダ単位では止まりません。**
別のタスクフォルダや共通ファイルに書けば、**確認プロンプトは出ず、そのまま書き込まれます。**

したがって、**書き込みの直前に必ず自分でパスを読み上げて確認**してください。

    出力先: <インスタンスのルート>\<タスク名>\


**そのパスにタスクフォルダ名が入っているか** ——
これだけ見れば、ほとんどの事故は防げます。
カレントディレクトリの直下に、ファイルを直接置くことはありません。

---

## このファイルについて

AI-DESK の規則の本文は **`AGENTS.md`** です。
このファイルは、そこへの**案内板にすぎません。**
（`CLAUDE.md` も同じく、Claude Code 用の案内板です。規則は書かれていません）

**ここにルールを書き足さないでください。** 二重管理になり、必ず食い違います。

`AGENTS.md` の中では、エージェント固有の項目に
**【Claude Code のみ】** / **【Claude Code 以外】** の印がついています。
あなたは **【Claude Code 以外】** の項目に従い、**【Claude Code のみ】** の項目は読み飛ばしてください。

なお `AGENTS.md` は**配布物のコピー**です。**この場で直接編集しないでください。**
規則を直したいときは、改訂案を `<タスクフォルダ>\` に出力し、管理者に渡してください。
