**まず、AI に「疎通確認」と言ってください。** 環境を一通り点検して、何が起きているか、次に何をすればよいかを教えてくれます。

---

## 資料が読めない

次の順に確かめてください。

1. **そのフォルダを、エクスプローラーで開けますか。** ネットワークドライブが繋がっていないことがあります
2. **「Block from now on」を選んだことはありませんか。** 初めて AI-DESK の外を読むときの確認でこれを選ぶと、外を読めなくなります。`疎通確認` が直し方を案内します
3. **依頼の「見る場所」に書いてありますか。** 書いていない場所は、AI が開く前に確認します
4. **`PROFILE.md` の「AI に読ませない場所」に入っていませんか。** そこは開きません

## Excel・Word・PDF が読めない

AI は Python を使って読みます。Python が無い PC では、AI が「導入してよいですか」と聞いてきます。

- 承諾すると、`bin\setup_python.ps1` で、あなたのユーザー領域にだけ入れます（管理者権限は不要）
- 入れた直後は、同じ会話では使えないことがあります。**Claude Code を起動し直してください**
- 一太郎（`.jtd`）など、直接読めない形式は、PDF やテキストに書き出して渡してください
- 自己解凍書庫（`.exe`）は実行しません。展開したファイルを渡してください

## 「書き込み制限で止められました」と言われた

**正しい動作です。** AI が、タスクフォルダの外など、書いてはいけない場所に書こうとしました。
AI はそのことを報告して止まります。どこに書こうとしたかを聞いて、依頼の伝え方を見直してください。

## `疎通確認` で、書き込みの制限が「異常」と出た

**作業を始める前に直してください。** 書き込みの制限が効かないと、資料フォルダへの書き込みも、`00_TASK.md` の上書きも止まりません。

1. 「このフォルダを信頼しますか」に承諾しましたか（**承諾していないと、制限は動きません**）
2. Claude Code を最新版に更新して、試し直す（`claude --version` で版が分かります）
3. 会社の設定（グループポリシー）で、PowerShell のスクリプトの実行が禁止されていないか、管理者に確かめる
4. **Windows 以外の PC で開いていませんか。** AI-DESK は Windows 専用です。macOS・Linux では制限が動きません

## 過去の会話（履歴）が一覧に出ない

AI-DESK を**ネットワークドライブ（`Z:` など）に置いている**と起きます。Claude Code 側の不具合で、**履歴は消えていません。**

- **AI-DESK は、会話を始めるたびに自動で直します**（あなたのユーザーフォルダに、同じフォルダへの別の入口を1つ作るだけです）
- それでも出ないときは、AI に「**履歴が出ない**」と伝えてください。状態を調べ、直してよいか聞いてきます
- 直したら、履歴の一覧を開き直してください（出なければ、VS Code の「Developer: Reload Window」）
- 急ぐときは、ターミナルで `claude --resume` を使うと、過去の会話を選べます

**AI-DESK 以外のフォルダ**で同じ症状が出たときは、AI-DESK の `bin\setup_history.ps1` を1つだけ、そのフォルダの Claude Code に渡して（チャットに添付するか、そのフォルダに置く）、「**これを実行して**」と頼んでください。

フォルダを移動・改名したときも、前の会話は一覧に出なくなります。続きは作業記録から再開できます。

## 間違った場所にファイルが作られた

AI は自分ではファイルを消しません。**どこに何を作ったかを報告する**ので、確かめてから、あなたが消してください。

## 「この AI-DESK には、まだ組織の情報が登録されていません」と言われる

`PROFILE.md` がまだ無いか、記入例のままです。「**初期設定**」と言えば、対話で作れます。
そのまま作業を続けても構いません（同じ会話では二度と言われません）。

手で書きたいときは、`PROFILE.example.md` をコピーして `PROFILE.md` という名前にし、書き換えます。
**1行目（`AI-DESK-PROFILE-EXAMPLE` と書いてある行）は、必ず消してください。** 残っていると、記入例のままと判断されます。

## 自分の AI-DESK が最新か知りたい

`疎通確認` で版番号が分かります。スクリプトで作った AI-DESK なら、配布元の版と自動で比べて、古ければ教えてくれます。
更新は管理者に頼んでください（→ [インストール](/repos/AI-DESK-DEV/インストール) の 4.）。

## 古い資料に、いまと違うフォルダの場所が書いてある

**書き換えないでください。** 当時の記録です。AI は、読むときに今の場所へ読み替えます。
読み替えのルールは `PROFILE.md` に書きます。

## AI-DESK は Claude Code のことですか

いいえ。AI-DESK は**この作業場と規則の名前**です。Claude Code でも Antigravity でも、ここで作業するときは AI-DESK の規則に従います。
ただし、書き込みの制限が機械的に効くのは Claude Code だけです。
