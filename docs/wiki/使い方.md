## 1. ふだんは、そのまま話しかける

AI-DESK のフォルダで Claude Code を起動して、頼みたいことをそのまま書きます。

```
メールの差出人名簿を作ってほしいです。
Z:\30_総務\受信メール のメールから差出人の署名を抽出して、名簿にしてください。
形式は xlsx で。重複はまとめて、差出人ごとの件数も入れてください。
```

AI が次のことをします。

1. **タスクフォルダを作る**（例: `差出人名簿\`）。始める前に「`出力先: …`」と示します
2. 頼まれたことを `01A_依頼内容.md` に書き留める（**言った言葉がそのまま残ります**）
3. 作業して、同じフォルダに `01B_…` という名前で成果物を出す
4. 作ったファイルの場所をフルパスで報告し、**「次にできること」を番号付きで**示す

```
AI-DESK\
    差出人名簿\
        00_作業記録.md                       ← これまでの経緯（AI が書く）
        01A_依頼内容.md                      ← 1回目に頼んだこと
        01B_差出人名簿_2026-09-16.xlsx        ← 1回目の成果物
        材料\                               ← AI が使った道具・途中のデータ
```

**名前の読み方は、これだけです。**

- 頭の **`01` `02`** は、何回目の依頼か
- **`A` があなたの依頼、`B` がその結果**

フォルダ名が気に入らなければ、**あとからあなたが変えて構いません**（AI は変えません）。

### 頼むときのコツ

- **資料の場所を伝えてください。** 正確なパスでなくても、「営業部の設備関係の資料」程度の手がかりで役に立ちます
- **欲しい形を伝えてください。** 「xlsx で」「A4 一枚で」「比較表で」など
- **目的を先に言うと**、AI の判断がぶれません
- 質問や相談だけなら、タスクフォルダは作られません

## 2. 続きを頼む

```
差出人名簿 の続き
差出人名簿 の2番で
```

AI は `00_作業記録.md` を読んで、前回の続きから始めます。
**「次にできること」の番号で答えられます。** 「2番、ただし〜」のように付け足しても構いません。

2回目の結果は `02A_依頼内容.md` と `02B_…` になります。**前の回の成果物は残ります。**
「短くして」と頼んだ回でも、結果は別のファイルになるので、見比べてどちらを使うか決められます。

新しい会話を始めても、続きは作業記録から再開できます。

---

## 3. 直すファイルや名前を、自分で決める

回ごとに `02B` `03B` と増やさずに、**1つのファイルを直していきたい**ときは、ファイルを名前で指定します。

```
今後は 02B を直して
今後は 議事録.md を直していって
今回だけ 議事録.md という名前で出して
```

- **名前は、タスクフォルダの中なら自由**に決められます。まだ無い名前なら、AI がいちばん新しい成果物を写して作ります
- **直す前の版は消えません。** AI が `材料\` の中に残します（例: `材料\議事録_第04回の前.md`）
- 「今後は」は次の回からも、「今回だけ」はその回だけです
- 元の出し方に戻すときは「**元に戻して**」と言います
- 頼まない限り、AI が勝手に出し方を変えることはありません

## 4. 込み入った依頼は、依頼書（`00_TASK.md`）に書く

ふだんは話しかけるだけで足ります。次のようなときだけ、依頼書を書きます。

- **同じ依頼を何度も繰り返す**（毎月の集計など）
- **依頼が込み入っていて**、話し言葉では伝えきれない
- **頼む人と、作業を見る人が違う**

手順です。

1. `AI-DESK\` の直下に、依頼の名前でフォルダを作る（例: `202610_見積比較\`）
2. `00_タスクテンプレート\00_TASK.md` をそのフォルダにコピーして、中身を埋める（**普通の日本語の文章で構いません。空欄があっても動きます**）
3. AI に「**202610_見積比較 をやって**」と言う

依頼書の項目は「概要」「見る場所」「依頼事項」「注意してほしいこと」「完成の条件」の5つです。
**いちばん大事なのは「見る場所」です。** AI は、ここに書いた場所の資料だけを読みます。

`00_TASK.md` は、あなたが書く依頼の原本です。**AI には書き換えられません。**
チャットで頼んだときに AI が書き留めた `01A_依頼内容.md` を、`00_TASK.md` という名前でコピーすれば、次からは依頼書の方式になります。

## 5. 資料の読み方と、読ませたくない場所

- **読んでよいフォルダを、前もって設定する必要はありません。** AI は依頼に必要なところを読みます
- 依頼の「見る場所」に場所を書いたときは、**その範囲だけ**を読みます。ほかも見る必要が出たときは、開く前に聞いてきます
- **いつも読ませたくない場所**（人事・給与など）は、`PROFILE.md` の「AI に読ませない場所」に書きます。「`○○` は読ませないで、と PROFILE に足して」と言えば、AI が書き足します

どちらも **AI への約束**で、機械的に読めなくする設定ではありません。

---

## 6. タスクフォルダが増えたら — 保管庫

古いタスクフォルダは、**`_保管庫\` に移してください。** 移すのはあなたです（AI は移動しません）。

```
AI-DESK\
    差出人名簿\               ← いま使っているもの
    _保管庫_仕事\
        202610_見積比較\       ← 移したもの
    _保管庫_趣味\
        旅行の計画\
```

- **名前が `_保管` で始まるフォルダ**が保管庫です。`_保管庫_仕事` のように改名しても、いくつ増やしても構いません
- 保管庫の中に置くのはタスクフォルダだけです。保管庫の中に、さらに保管庫は作れません
- **保管したタスクも、その場所のまま続けられます**

| 頼み方 | AI がすること |
|---|---|
| 「202610_見積比較 の続き」 | 保管庫の中から見つけて、「`_保管庫_仕事\202610_見積比較` のことですか」と確かめてから続ける |
| 「_保管庫_仕事\202610_見積比較 の続き」 | 確かめずに続ける |
| 同じ名前が2か所以上にある | どれのことか聞く |

## 7. 組織の前提知識とスキル

- **`PROFILE.md`** には、この組織の事情（業態・社内の言葉・資料の場所・読ませない場所）を書きます。自由に直して構いません。「PROFILE に足して」と言えば、AI が書き足します
- **スキル**は、型の決まった業務の手順です。よく頼む作業を「**スキルにして**」と言えば、AI が内容を説明し、同意を得てから作ります
  - 最初から入っている `初期設定`・`疎通確認`・`新規タスク`・`継続タスク` を直接直すと、次の更新で消えます。手を入れたいときは、別の名前でコピーを作ってもらいます

---

## 8. 気をつけること

- **大事な原本を、タスクフォルダに置かないでください。** 頼まない限り AI は書き換えませんが、設定では止めていません
- **同じタスクフォルダを、2つの会話で同時に使わないでください。** 作業記録が食い違います
- **`CLAUDE.md` を直さないでください。** 配布物のコピーで、次の更新で消えます。直したいところがあれば、AI に改訂案をタスクフォルダへ出させて、管理者に渡してください
- **確認を出すモードで使うときは**、身に覚えのない書き込みの確認が出たら、承認せずに断ってください
- **AI が報告するファイルの場所を見てください。** タスクフォルダ以外の場所が書かれていたら、その場で伝えてください
