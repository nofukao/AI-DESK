## 1. 用意するもの

- **Windows 10 / 11 の PC**
- **Claude Code**。VS Code の拡張機能か、ターミナルの `claude` コマンドのどちらかで使います
- Python は、**入れておかなくて構いません。** Office・PDF を読むときに無ければ、AI が承諾を得てから入れます

---

## 2. インスタンスを作る

### 方法A: スクリプトで作る（おすすめ）

開発リポジトリ（または配布原本のある場所）の PowerShell で、次を実行します。

```powershell
.\bin\new-instance.ps1 -Dest "<置きたい場所>" -Name "AI-DESK"
```

社内の配布原本から作るときは、`-Source` を付けます。

```powershell
.\bin\new-instance.ps1 -Dest "<置きたい場所>" -Name "AI-DESK" -Source "<配布原本>\AI-DESK"
```

- どこから作ったかが `.ai-desk\source.txt` に記録されます。**`疎通確認` が、配布元の版と自動で比べられるようになります**
- `PROFILE.md` は作られません（3. の「初期設定」で作ります）

### 方法B: フォルダをコピーする

配布物の `AI-DESK` フォルダを、エクスプローラーで目的の場所へコピーしても使えます。
この場合、`source.txt` が無いので、`疎通確認` の版の比較だけが「確認できませんでした」になります。

> **使っている AI-DESK を、コピーして増やさないでください。**
> タスクフォルダ（業務の資料や成果物）まで一緒にコピーされます。新しく作るときは、**配られたままの AI-DESK** から作ってください。

### 置き場所の注意

- **深い場所に置かないでください。** Windows にはパスの長さ（260 文字）の制限があり、日本語のタスク名と重なると意外に早く届きます
- **ネットワークドライブ（`Z:` など）に置いても使えます。** Claude Code の履歴の一覧が出なくなる不具合がありますが、AI-DESK が自動で直します（→ [困ったとき](/repos/AI-DESK-DEV/困ったとき)）

## 3. はじめて使うときの設定

### 3-1. そのフォルダで Claude Code を起動する

**VS Code の場合**

1. VS Code で、**AI-DESK のフォルダを開く**（「ファイル」→「フォルダーを開く」）
2. 「このフォルダの作成者を信頼しますか」と聞かれたら、**信頼する**を選ぶ
3. Claude Code の画面を開く

**ターミナルの場合**

```powershell
cd "<AI-DESK のフォルダ>"
claude
```

### 3-2. 【重要】「このフォルダを信頼しますか」に承諾する

初回だけ、Claude Code がこの確認を出します。**必ず承諾してください。**
**断ると、書き込みの制限（hook）が動きません。** AI がタスクフォルダの外にも書けてしまいます。

### 3-3. 「初期設定」と言う

```
初期設定
```

AI が質問しながら、`PROFILE.md`（この組織の前提知識）を作ります。

- **聞かれたことに答えるだけです。** 分からなければ「分からない」「飛ばして」で構いません
- 資料のあるフォルダは、AI が一覧を見せてくれるので、選ぶだけです
- **AI に読ませたくないフォルダ**（人事・給与など）があれば、ここで伝えます
- 「要らない」と答えても構いません。前提知識が無くても動きます

### 3-4. 「疎通確認」と言う

```
疎通確認
```

AI が環境を一通り点検して、**場所・版番号・資料を読めるか・書き込みの制限が効いているか**を報告します。
途中で「わざと間違った場所へ書き込もうとします」と言われます。**止められるのが正しい動作です。**

これで準備は終わりです。

### 3-5. 初めて AI-DESK の外の資料を読むとき

Claude Code が「この先も読み続けてよいか」を英語で聞いてくることがあります。

| 表示 | どうするか |
|---|---|
| **Keep allowing** | **これを選ぶ** |
| Block from now on | **選ばない。** この PC のすべての作業で、AI-DESK の外を読めなくなります |
| Ask again next time | 今回は読まず、次にまた聞かれます |

## 4. 新しい版に更新する

開発リポジトリの PowerShell で、次を実行します。

```powershell
.\bin\update-instance.ps1 -Path "<インスタンスのパス>" -WhatIf   # 何が変わるかを見るだけ
.\bin\update-instance.ps1 -Path "<インスタンスのパス>"           # 実行
```

- **配布物のファイルだけを上書きします。** タスクフォルダ・`PROFILE.md`・`settings.local.json`・`source.txt`・利用者が足したスキルには触れません
- **何も削除しません。** 上書きするファイルは、先に `.ai-desk\backup\<前の版>\` へ退避します
- 配布元は、既定でそのインスタンスの `source.txt` に書かれた場所です（`-Source` で指定もできます）
- 更新したら、`疎通確認` で「最新です」と出ることを確かめてください

---

## 5. 社内の配布原本を更新する

```powershell
.\bin\publish.ps1 -Dest "<配布原本の親フォルダ>" -WhatIf   # 置かれる内容を見るだけ
.\bin\publish.ps1 -Dest "<配布原本の親フォルダ>"
```

`-Dest` の下に `AI-DESK\` を作ります。既にあれば、確認してから上書きします。
書き込み先が共有フォルダになるため、**このスクリプトは人が実行します**（AI には頼みません）。

## 6. 移動・改名・共有

| したいこと | できるか |
|---|---|
| インスタンスのフォルダを、別の場所・別の PC へ移す | **できます。** 目印は `.ai-desk\VERSION` なので、場所は問いません |
| インスタンスのフォルダ名を変える | **できます** |
| タスクフォルダの名前を変える | **できます。** 次からは新しい名前で「〜の続き」と言います |
| 共有フォルダに置いて、複数の PC から使う | **できます。** ただし、**同じタスクフォルダを、2つの会話で同時に使わないでください** |

- Claude Code の会話の履歴は、**フォルダの場所ごと**に記録されます。移動・改名すると、前の会話は一覧に出なくなります（消えてはいません）。続きは作業記録から再開できるので、困りません
- `source.txt` に書かれた配布元は、移動しても変わりません
