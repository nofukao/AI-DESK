# AI-DESK-DEV

**AI-DESK** の開発リポジトリです。

## AI-DESK とは

手元の資料を AI に読ませて、まとめ・議事録・比較表などを作らせるための**作業場**です。
名前の由来は「机」——「**資料は書庫から自由に読めるが、書けるのは自分の机の上だけ**」という
約束を、名前そのもので表しています。
フォルダごとコピーして、どこにでも置いて使えます。

---

## 開発リポジトリとインスタンスの関係

```
  AI-DESK-DEV\              ← このリポジトリ（git 管理下）
      AI-DESK\              ← ★配布物。これをコピーするとインスタンスになる
      bin\new-instance.ps1  ← コピーする道具
              |
              |  publish.ps1（人が実行）
              v
  <社内の配布原本>\AI-DESK\   ← 社内で1か所。ここが「原本」
              |
              |  new-instance.ps1 / update-instance.ps1
              v
  <任意の場所>\AI-DESK1\      ← インスタンス（業務で使う）
      CLAUDE.md              配布物のコピー
      PROFILE.md             ★この組織の前提知識（配布されない）
      .claude\settings.local.json  ★読んでよいフォルダ（配布されない）
      .ai-desk\VERSION       ★ここがインスタンスのルートだという目印
      202610_見積比較\        ← 業務データ（タスクフォルダ）
          task.md
          out\               ← AI が書き込める唯一の場所
```

**インスタンスの識別は、フォルダ名ではなく `.ai-desk\VERSION` の有無で行います。**
名前は自由で、同じ PC・同じ共有にいくつ置いてもかまいません。

---

## インスタンスは git クローンではありません

**配布物フォルダの「コピー」です。インスタンスの中に `.git` は存在しません。**

理由は1つです。インスタンスの中には業務の**機密情報**が入ります。
そこに `.git` があると、誰かが `git add .` と `git push` をした瞬間に外部へ出ます。
**push は実質的に取り消せません。**

配布物 `AI-DESK\CLAUDE.md` の「絶対遵守ルール2: Git の不使用」は、これを防ぐためのものです。
**開発リポジトリだけが例外**として git を使います。

## 使い方

### インスタンスを新しく作る

```powershell
.\bin\new-instance.ps1 -Dest "<置きたい場所>" -Name "AI-DESK"
```

作られたら、利用者に次を案内してください。

1. `PROFILE.md` に組織の前提知識を書く（`PROFILE.example.md` の写しが置かれています）
2. `.claude\settings.local.json` に、読んでよいフォルダを書く
3. そのフォルダで `claude` を起動し、`疎通確認` と言う
4. **初回の「このフォルダを信頼しますか」に必ず承諾する**（最頻出のつまずきです）

### 既存のインスタンスを新しい版に更新する

```powershell
.\bin\update-instance.ps1 -Path "<インスタンスのパス>" -WhatIf   # 差分を見るだけ
.\bin\update-instance.ps1 -Path "<インスタンスのパス>"           # 実行
```

**配布物のファイルだけを上書きします。** タスクフォルダ・`PROFILE.md`・
`settings.local.json` には触れません。削除も行いません。

### 社内の配布原本を更新する

```powershell
.\bin\publish.ps1 -Dest "<社内の配布原本の親フォルダ>"
```

## 版ずれについて

`CLAUDE.md` はインスタンスの数だけコピーが存在するため、**必ず版がずれます。**
受け止め方を決めてあります。

1. `.ai-desk\VERSION` に版番号を持つ
2. `.ai-desk\source.txt` に「どこから来たか」を記録する
3. **`疎通確認` スキルが、配布元の版と比べてずれを知らせる**
4. `update-instance.ps1` は、上書き前に差分を表示する

## このリポジトリの構成

| 場所 | 内容 |
|---|---|
| `AI-DESK\` | **配布物。** これをコピーするとインスタンスになる |
| `bin\` | インスタンスを作る・更新する・配布原本へ publish するスクリプト |
| `docs\` | 設計の記録と移行手順 |
| `CLAUDE.md` | **開発者（と AI）向けの規則。配布されません** |
| `CHANGELOG.md` | 版ごとの変更履歴 |

**`AI-DESK\` の中で実際の業務を行わないでください。** 配布物であって、作業場ではありません。

---

## 開発上の約束

- `.ps1` は **BOM 付き UTF-8**、その他は **BOM なし UTF-8**
- 配布物にファイルを足したら、`.gitignore` のホワイトリストにも `!` 行を足す
- 版番号を上げたら `CHANGELOG.md` と `AI-DESK\.ai-desk\VERSION` の**両方**を直す
- 実在の会社名・物件名・個人名をリポジトリに入れない（Public 化の可能性があります）
- `Z:` は読み取り専用。実データは開かない

詳細は [CLAUDE.md](CLAUDE.md) を参照してください。
